# SmartStay-Hostel-Management

A full-stack web application designed to manage hostel operations efficiently. It supports Admin and Student roles with secure authentication, room allocation, fee management, and complaint handling.

Features
Admin
Manage students (add, update, delete, view)
Manage rooms and assign to students
Track available and occupied rooms
Manage fees (paid/unpaid status)
Handle student complaints

Student
View profile and assigned room
Check fee status
Submit complaints
Track complaint status


Tech Stack
Frontend: React.js / HTML, CSS, JavaScript
Backend: Node.js, Express.js
Database: MongoDB / MySQL
Authentication: JWT / bcrypt
